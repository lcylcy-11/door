# 문 좀 살살

## 2D 1인칭 공포 시안 — 문틈

`npm start` 실행 후 [공포 시안](http://127.0.0.1:5173/horror/)을 엽니다. 기존 버전은 `/2d/`에 보존했습니다.

02:17, 원룸의 중문 하나. 걸쇠를 풀고 문 너머를 확인한 뒤, 다시 닫고 잠그는 한 밤입니다. 천천히 문을 여는 긴장을 중심에 두고 일곱 긴장 기믹을 하나씩 가르친 뒤 겹칩니다. 깨끗하게 끝내면 약 4분, 처음이면 6–8분이 걸리며 실패하면 그 장(章)부터 다시 할 수 있습니다.

| 조작 | 마우스 | 키보드 |
|---|---|---|
| 손잡이 잡고 문 밀기 · 손과 힘겨루기(H2) | 왼쪽 버튼을 누른 채 좌우로 끌기. 손이 붙잡으면 → 힘 싣기, ← 힘 빼기 | Enter 잡기/놓기 · ←/→ · Space 놓기 |
| 시선 내리기 (문틈의 눈) | 오른쪽 버튼을 누르고 있는 동안. 왼쪽 버튼과 함께 눌러도 됩니다. 「시선 ↓」 버튼 또는 일시정지 메뉴에서 '눌러서 전환'으로 바꿀 수 있습니다 | S (전환) |
| 뒤돌아보기 (등 뒤의 서랍) | 화면 왼쪽 가장자리 「↶ 뒤」 클릭 (손잡이를 놓아야 합니다) | Q |
| 방 불 켜기 | 문 왼쪽 벽 스위치 클릭 (좁은 화면은 왼쪽 가장자리 「불」) | L |
| 슬리퍼 버팀목 | 바닥의 슬리퍼 클릭 → 문 밑에 끼우기/빼기 | W |
| 걸쇠 | 걸쇠 손잡이를 누른 채 위아래로 천천히. 중간 걸림쇠(툭)에서 잠깐 멈춥니다 | ↑/↓ |

일곱 기믹: **G1** 뻑뻑한 레일은 엘리베이터·차 소리가 덮을 때만 민다(소리만 덮고 눈·손은 못 속인다) · **G2** 처음과 마지막에 걸쇠를 천천히 · **G3** 문틈 위의 눈을 보지 않고 시선을 내린 채 손잡이를 다룬다 · **G4** 불을 켜면 유리 너머가 보이지만 딸깍 소리와 새는 빛이 들킨다 · **G5** 슬리퍼를 끼우면 잠깐 손을 놓을 수 있지만 문은 닫히지 않는다 · **G6** 문 가장자리의 손가락은 당신을 따라 한다 — 살짝 열고 멈춘 뒤, 따라 끄는 동안 닫는다 · **G7** 등 뒤의 서랍은 볼 때만 멈춘다. H2의 손 힘겨루기는 수치 그대로 유지했습니다.

모든 소리 신호는 자막(위치·내용)과 화면 신호를 함께 냅니다. 소리를 꺼도 규칙은 같습니다. `Esc` 일시정지는 시간과 소리를 함께 멈춥니다. 배경·문·손·새 소품은 로컬 2D 이미지, 효과음은 절차적 합성 Foley이며 출처는 `docs/horror-assets.json`과 `asset-packs/door-horror-gimmicks-v1/`에 있습니다. 모든 시간·임계값·조작 배치는 사람 체감 검토 전의 임시값이며 `dist/horror/tuning.js` 한 곳에 있습니다.

기존 버전은 원룸 중문을 조심히 여닫아 아랫집의 인내심을 지키는 **SVG 2D 게임**입니다. 귀여운 화면이 소음에 따라 급격하게 공포스러운 분위기로 바뀝니다.

![평온, 압박, 표정 전환, 폭발 연출](docs/preview.png)

## 실행

Node.js 20 이상에서 실행합니다. 추가 패키지 설치는 필요하지 않습니다.

```sh
npm start
```

브라우저에서 `http://127.0.0.1:5173/`을 엽니다. 파일로 실행하려면 `dist/2d/index.html`을 직접 열거나, `npm run standalone`으로 생성한 `build/quiet-door.html`을 엽니다.

## 조작과 규칙

- 위 화면의 손 모양을 누른 채 복잡한 경로를 따라 움직입니다. 이동량에 맞춰 중문이 열리고 닫힙니다.
- 구간별로 **살살 / 보통 / 빠르게** 요구 속도가 바뀝니다. 경로를 벗어나거나 속도를 맞추지 못하면 소음이 발생합니다.
- 아래 화면은 아랫집 캐릭터의 얼굴 클로즈업입니다. 소음이 쌓이면 위 화면이 내려오며 얼굴을 프레스처럼 누릅니다.
- 표정은 평온 → 불편 → 고통 순으로 변하다가, 인내심이 일정 수준을 넘으면 검은 눈과 기묘한 미소로 급변합니다. 화면 색감과 소리도 동시에 바뀝니다.
- 조작을 멈추면 소음과 압박이 풀립니다. 최종 한계에 도달하면 캐릭터가 폭발하며 위 화면을 부수고 게임이 끝납니다.
- 열기 → 닫기 → 열기 → 닫기, 네 번의 조작을 완료하면 성공합니다.
- **표정 변화** 버튼은 변화와 진정을, **폭발 연출** 버튼은 화면 파괴까지 자동으로 보여줍니다.
- 연습 모드는 폭발 후 계속 진행할 수 있습니다. `Esc`로 일시정지하고 소리·재시작 버튼을 사용할 수 있습니다.

기본 테마는 귀여운 버전입니다. 상단에서 코믹·호러 테마도 선택할 수 있습니다. 소리는 시작 버튼 등 사용자 입력 이후 활성화되며 진행 정보는 서버로 전송하지 않습니다.

## 검증

```sh
npm run check
npm test
npm run contours                       # 마스킹 판정용 음량 곡선이 WAV와 일치하는지
npm run play -- all --url=http://127.0.0.1:5173/horror/   # 공포 시안: 실제 마우스 입력(Edge/Chrome CDP)으로 성공·7가지 실패·재시도 재생 (npm start 실행 중일 때)
```

경로 건너뛰기 방지, 구간별 속도, 압박에 맞춘 마우스 좌표 변환, 공포 전환과 진정, 폭발 타임라인, 연습·시연 모드, 네 경로 완주, SVG 렌더링 및 화면 제어를 검증합니다.

## 파일 구성

- `dist/2d/`: 최신 SVG 2D 버전. `core.js`는 게임 상태, `paths.js`는 경로 판정, `portrait.js`는 얼굴·프레스·파괴 연출, `art.js`는 방과 중문을 그립니다.
- `dist/previous-3d.html`: 초기 3D 시안. 아래 화면에서 아랫집의 일상과 현관 접근을 보여줍니다.
- `scripts/`: 정적 서버, 문법 확인, 단일 HTML 생성 도구.
- `tests/`: 별도 설치 없이 실행하는 Node.js 테스트.
- `docs/`: 초기 기획 정리와 현재 연출 미리보기.

## 사용 라이브러리

최신 2D 버전은 외부 런타임 라이브러리 없이 SVG·CSS·JavaScript와 Web Audio로 동작합니다. 초기 3D 버전은 Three.js r160.1을 사용하며 MIT 라이선스 원문을 `dist/THREE-LICENSE.txt`에 보존했습니다. 캐릭터와 장면은 코드로 그린 벡터 도형입니다.
