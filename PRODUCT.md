# Product

## Platform

web

## Product Purpose

문 좀 살살 is a mouse-operated door game. The user approved a small 2D first-person horror prototype: operate one door, stop for downstairs knocks, close quickly when a hand enters the gap.

## Operating Context

Local browser prototype for the user to judge tension and interaction. Existing static HTML/CSS/JavaScript project; the original SVG game remains accessible at `/2d/`.

## Capabilities and Constraints

- One door, mouse drag, two legible signals requiring different responses.
- Scope is an early playable direction check, not the full previously proposed six-minute game.
- No deployment, account, analytics, save system or external runtime libraries.
- Final art, timing, tension and product acceptance remain open to the user.

## Evidence on Hand

Prior discussion supplied and user approved the first-person, limited-view, door-drag direction. The latest request is the implementation authority. README and the original planning document describe earlier versions, not an approval of every proposed horror rule.
