# 에셋 팩 검증 범위

## 파일과 제작물

- 신규 PNG 9종, 기존 H2 참조 PNG 4종, WAV 18종.
- PNG는 내장 이미지 생성 도구로 제작하고 정확한 프롬프트를 `image-provenance.json`과 파일 메타데이터에 기록했다. 참조 네 장은 기존 파일을 변경 없이 복사했다.
- WAV는 `tools/build_audio.py`의 고정 난수 시드와 절차적 합성으로 제작했다. 현장/성우 녹음이 아니다.
- `manifest.json`은 모든 기믹의 파일 매핑, 크기/알파 경계, 부품 합성 출발점, 재생 시간/루프 프레임, SHA-256을 담는다.

검사 도구는 게임을 실행하거나 수정하지 않는다. `validation.json`은 파일 규격 검증이며 플레이 PASS가 아니다. 기존 `ref-hand`는 의도적으로 손목이 오른쪽 화면 밖에서 들어오는 그림이므로 원본 알파 일부가 캔버스 경계에 닿는다. 신규 에셋의 잘림 결함을 숨기는 경고가 아니다.

## 제작 중 수정

별도 읽기 전용 인계 검토에서 G1–G7의 파일 연결과 미구현 범위, 앵커/루프 단위, 걸쇠 가림 안내에 중대한 누락이나 모순이 발견되지 않았다. 이 검토는 청취·플레이 검증을 대신하지 않는다. 실제 브라우저 캡처는 루트의 ignored `.impeccable/review/h3-assets/`에 보존했다.

첫 음원 검사에서 단발 음원에 창 함수를 씌운 뒤 DC가 재도입되는 것을 발견했다. 시작/끝 0을 유지하는 창 가중 보정으로 수정했고, 동일 검사에서 통과했다. 검사를 약하게 바꾸지 않았다.

서랍 앞판은 배경의 빈 공간보다 처음 형태가 깊어 한 번 넓고 얕은 형태로 재생성했다. 선택된 최종 파일만 포함했다. 에셋의 정확한 게임 내 맞춤·서랍 깊이·마우스 판정은 구현 이후 확인해야 한다.

## 제작 도구

`tools/build_audio.py`, `build_manifest.py`, `validate_pack.py`, `build_preview.py`는 이 폴더 안의 에셋 제작/검사/목록 도구다. 게임 구현 코드가 아니다. Python + numpy + Pillow가 있는 제작 환경에서 쓸 수 있고, 사용자는 결과 PNG/WAV/JSON/HTML을 그대로 이용하면 된다.
